ABSTRACT Most machine learning-based network intrusion detection systems (NIDS) rely on perflow time-agnostic feature vectors, representing each flow using structural NetFlow features without
explicit temporal information. This representation limits the ability to capture the intrinsic temporal
structure of network traffic, such as event sequencing, inter-arrival dynamics, and non-stationary rate
fluctuations. Consequently, the contribution of these temporal dependencies to detection performance
remains under-characterised. In this work, we evaluate the extent to which sequential architectures,
specifically Transformers, Long Short-Term Memory networks, and one-dimensional Convolutional Neural
Networks, can exploit time-dependent information under controlled cross-dataset conditions. To facilitate
this analysis, we introduce NF3, a temporally enriched extension of existing NetFlow-based benchmarks,
which integrates fine-grained timestamps and inter-arrival-time statistics. Using these augmented datasets,
we quantify temporal regularities in benign and malicious traffic and benchmark the ability of each
architecture to learn time-dependent representations in both binary and multi-class settings. Our results
demonstrate that augmenting conventional flow features with temporal information yields consistent gains;
binary detection improves by up to 3% in F1 score, while macro-averaged multi-class F1 increases by
approximately 27%, with the most significant improvements occurring in attack classes with pronounced
temporal signatures. These findings indicate that incorporating time-dependent information enhances both
the discriminative power and behavioural interpretability of modern NIDS.
INDEX TERMS Intrusion detection systems (IDS), NetFlow data, network traffic classification, sequential
deep learning models, temporal network analysis, transformers and LSTM networks.

II. RELATED WORKS

Prior studies [17], [27], [28], [29] have systematically
analysed feature importance in flow-based NIDS datasets.
Awad et al. [17] performed correlation-based and thresholddriven selection on a large NetFlow-formatted IoT intrusion
dataset containing over 17 million flows, reducing the
number of features to 13 while maintaining up to 100%
detection accuracy. Binbusayyis and Vaiyapuri citebib:27
conducted a comprehensive analysis to recommend the most
effective feature evaluation measure for intrusion detection.
Their study compared consistency-based, correlation-based,
information-theoretic (information gain), and distance-based
criteria, each reflecting a different strategy for identifying
informative features. The evaluation was performed on two
benchmark datasets: NSL-KDD [30] and UNSW-NB15 [31],
and found that the consistency-based measure provided the
best performance. Their results indicated that an optimal
subset of features significantly improves detection accuracy.
This underscores the value of identifying impactful features,
such as the temporal ones in our study. Sarhan et al. [28]
applied the SHAP technique [32] to evaluate the contribution
of NetFlow features and offer insight into how individual
features affect model predictions. Choi et al. [29] extended
this direction with an attack-specific analysis framework
using NF-BoT-IoT-v2 and NF-ToN-IoT-v2 datasets, identifying dominant features for each attack type and demonstrating
improved performance with reduced dimensionality.
Beyond general feature analyses at the dataset level, several
works have focused on individual NetFlow features. One
commonly studied feature is flow length, which provides

performance of the LSTM to a static Feed-forward Neural

III. NF3: NetFlow DATASETS WITH TEMPORAL FEATURES

This section outlines the structure and preparation pipeline
of the NF3 datasets. Building on the methodology used to
generate the earlier versions [20], [21], NF3 extends the
datasets by introducing a temporal dimension through the
inclusion of fine-grained timestamps and IAT features.
A. NEW FEATURES

Table 1 summarises the features included in this version of the
datasets alongside those of previous versions. As shown, the
new release retains all the features of the previous versions
and introduces an additional set of ten temporal features.
These new features fall into two categories: timestamp features (highlighted in green), which specify the start and end
times of flows in milliseconds, and IAT features (highlighted
in blue), which capture various statistical measures of the
inter-arrival times between consecutive packets within a flow.
Timestamps allow for the precise ordering of events within
a network. They are also helpful in accurately calculating
flow durations, which are important for detecting abnormally
long or short connections that might indicate malicious
activity [47]. Historical timestamp data allows for the creation
of baselines of normal network behaviour (e.g., typical traffic
patterns during different times of day [38], [40]). Deviations
from these baselines can then be identified as anomalies. This
temporal granularity is necessary for the advanced analyses
and correlations that will be explored in the subsequent
sections.
IAT is a key temporal metric that measures the elapsed
time between consecutive packets at a monitoring point [40].
When calculated in a specific direction, either from source to
destination or in reverse, IAT exposes fine-grained patterns
in traffic behaviour, such as flow regularity, congestion, and
burstiness [36]. Although IAT is defined at the packet level,
it becomes particularly informative when aggregated at the
flow level. To compute this metric accurately, each packet’s
timestamp is recorded upon arrival, and the difference
between consecutive timestamps is determined. These time
differences are then aggregated to obtain the minimum,
maximum, average, and standard deviation for each flow. The
resulting set of metrics forms a concise temporal signature
that can uncover traffic anomalies not evident from volume
or structural features alone [37].

A. FLOW DURATION DISTRIBUTION (FDD)

Flow duration is a fundamental temporal attribute that
represents how long a communication persists between
endpoints [47]. Assessing these distributions helps to reveal
behavioural differences between benign and malicious traffic,
such as short bursts in scans versus prolonged sessions in data
exfiltration. Here, we assess the flow duration distributions to
investigate how different attack classes vary in the length of
their network sessions and whether these temporal patterns
diverge from benign behaviour. As shown in Figure 2,
each histogram illustrates the frequency of flows across
logarithmically scaled duration ranges for all traffic classes
in the four NF3 datasets. Flow durations are capped at
two-minute intervals to align with the NetFlow exporter
configuration.
In NF-UNSW, the overall FDD is dominated by shortlived flows across nearly all classes. Certain attack classes,
such as Worms and Analysis, remain strictly confined below
two or three seconds. In NF-CIC, the distribution becomes
more diverse. The benign traffic shows a uniform spread
across the entire duration range. DoS and Infilteration attacks
also extend across nearly the entire durations. Other attack
types are mostly concentrated below one minute. In NF-ToN,
although it includes nine attack classes, the majority of flows
occur within very short durations. Only Password and MITM
attacks, along with benign traffic, extend into longer duration
ranges. The remaining attacks are tightly clustered near the
lower duration bins. Finally, in NF-BoT, there is no clear
distinction among attack classes in terms of flow duration.
The distribution shows that certain duration bins contain a
dominant number of flows, while comparatively fewer flows
appear in other ranges.

attack class helps validate the correctness of ground-truth

datasets. This information clarifies whether attacks appear
as isolated events or overlap with benign activity, which
directly influences the difficulty of learning and detection.

V. EVALUATION PIPELINE

To investigate the role of the temporal features in attack
detection, we evaluate their effectiveness using three sequential deep learning models, namely LSTM, 1D-CNN, and
Transformer architectures.
Preprocessing: The evaluation begins with a structured
preprocessing step to prepare the NetFlow data for sequential
learning. Separate procedures are used for numerical and
categorical attributes.
We apply MinMax normalisation to scale all numeric
NetFlow features to the [0, 1] range. Categorical fields
are processed using One-Hot Encoding (OHE) for the top
20 most frequent values. Specifically, the top 20 are identified
and encoded as separate binary values, while all other
values are grouped into a single category labelled Other.
This method allows the model to capture patterns from
common categorical values while maintaining computational
efficiency. The encoding strategy follows best practices
established in prior work that investigated preprocessing
strategies for categorical data in NIDS settings [53].
The timestamp features FLOW_START_MILLISECONDS
and FLOW_END_MILLISECONDS were originally recorded
66906

in Unix time (i.e., milliseconds since 1970), resulting in
large absolute values. These are not meaningful for flow-level
learning and can negatively impact model stability. Therefore,
we first shift these values so that the earliest flow starts at
0 milliseconds, aligning all flows relative to the beginning of
the dataset. The shifted values are then scaled to [0, 1] using
MinMax normalisation.
To prevent biased learning and ensure a fair, generalisable
evaluation, we exclude non-temporal features that are known
to correlate strongly with specific attack types [17], [54]. Previous studies [21], [54] have shown that including identifiers
such as IP addresses and port numbers can artificially boost
model performance by allowing models to learn from datasetspecific artefacts rather than genuine behavioural patterns.
In particular, [21], [54] reported biased prediction outcomes
when Time-to-Live (TTL) features were included in the
UNSW-NB15 dataset. Although this issue was specific to
the UNSW-NB15 dataset, we removed TTL features from all
four NF3 datasets to maintain consistency across evaluations.
Accordingly, we exclude all features related to IP addresses,
port numbers, and TTL values to promote generalisation and
ensure the models focus on broader traffic behaviours rather
than memorising flow-specific details.
Sequence Construction: The datasets are transformed
into fixed-length sequences before being fed into the models.
Each sequence consists of N consecutive flows, preserving
the natural order of NetFlow records as they appear in the
datasets. This ordering follows the chronological sequence of
flow observations and enables the models to capture temporal
dependencies across multiple flows. Rather than assigning
a single label to an entire sequence, this study adopts a
sequence labelling strategy, where each element (i.e. each
flow) retains its original class label within the sequence [55].
Essentially, the model then takes into consideration the
temporally adjacent neighbour flows.
To determine an appropriate sequence length N ,
an exploratory study was conducted by evaluating model

(patience = 3) and restoring the best-performing weights.
The time-distributed layer enables the model to produce a
prediction for each flow within the sequence. The LSTM
employs four bidirectional recurrent layers of ten units each
to capture sequential correlations. The 1D-CNN consists
of three convolutional layers with 64, 128, and 256 filters

four encoder layers (hidden dimension = 64, two attention

influence of temporal features while keeping the architectural
complexity comparable.
Finally, the trained models are subsequently evaluated
using a shuffling-based permutation analysis to investigate
the role of temporal features in influencing model decisions.

C. PERMUTATION ANALYSIS

The initial comparative evaluations between models with
and without temporal features are essential to establish
the practical impact of incorporating these features across
different architectures and datasets. This stage provides a
broad understanding of how temporal information influences
model performance under realistic conditions. However, such
evaluations alone cannot fully isolate the specific contribution
66909

M. Luay et al.: Time Matters: Temporal NetFlow Features for ML-Based Network Intrusion Detection

of temporal features, as the model architectures and input
representations inevitably change when new features are
introduced. After confirming the overall effect in the previous
section, we conduct a permutation analysis [26] in this
section, as a complementary step to more accurately quantify
the role of temporal features within a fixed model. This twostage approach provides both empirical validation through
direct performance comparison and causal insight through
controlled feature importance analysis.
Permutation analysis is a model-agnostic technique that
estimates the contribution of a feature (or group of features)
by measuring the degradation in classification performance
when the feature values are randomly shuffled. In our
permutation analysis, we combine the related features into
three groups as shown in Table 7.
The Durations group includes three features, that existed
in the previous versions of the datasets. The Timestamps
group includes the flow start and end times (in milliseconds),
and the IAT group includes all inter-arrival time statistics for
source-to-destination and destination-to-source flows.
We first shuffle each group independently to examine
its individual contributions to classification performance.
Next, we shuffle all temporal features simultaneously to
evaluate their collective importance. These experiments are
performed for both binary and multi-class classification tasks.
If shuffling the temporal features results in a substantial drop
in performance, it indicates that the models rely on temporal
information; if it leads to little or no change, it suggests that
the models do not strongly depend on these features.
Figure 7 shows the results of the permutation analysis for
the binary classification task across the four NF3 datasets
using the LSTM, 1D-CNN, and Transformer models. The
solid orange bars represent the baseline F1 scores with
unshuffled data, while the subsequent bars illustrate performance when timestamps, durations, IAT, and all temporal
features are shuffled.
Across all datasets, shuffling temporal features leads to
noticeable performance degradation, confirming that the
models rely on temporal information to varying degrees.
For NF-UNSW, all models achieve strong baselines (94–
99% F1), but timestamp shuffling causes a sharp decline,
most notably for the LSTM (47.19%), while 1D-CNN and
Transformer remain more robust (83.63% and 98.66%).
In NF-ToN, where baseline scores are 93–95%, timestamp
shuffling again results in substantial drops (around 63.98%),
whereas IAT and duration shuffling have smaller effects,
suggesting timestamps are the dominant temporal factor.
For NF-CIC, all temporal groups contribute significantly;
LSTM performance falls from 96.66% to between 60–74%,
with similar declines for CNN and Transformer (65.56%
and 72.70%), showing that temporal dynamics are central to
this dataset. In contrast, NF-BoT remains almost unaffected
(around 99%), reflecting its severe class imbalance and
limited temporal dependency.
Overall, the analysis demonstrates that temporal features
are vital for effective binary attack detection in most

This study provides a systematic examination of the role of
temporal information in flow-based network intrusion detection. By extending existing NetFlow benchmarks to create the
NF3 datasets, two new temporal feature groups, timestamps
and IAT statistics, were added to the previously available
duration features. This enhancement enabled a detailed
investigation of how time-dependent patterns influence
both binary and multi-class attack detection. Comparative
evaluations and permutation analyses conducted across four
benchmark datasets showed that temporal features capture
behavioural patterns that time-agnostic flow features alone
cannot represent. Among these, timestamps and IAT features
consistently proved to be the most informative, allowing finer
distinction between benign and malicious traffic. In contrast,
duration features, which were already included in NF2,
contributed less to overall performance improvements.
Experiments using sequential deep learning models confirmed that including temporal features improves detection
accuracy across different architectures and datasets. The
improvement was particularly notable in multi-class classification, where temporal information helps models separate
multiple attack types more effectively.
This study demonstrates that temporal features substantially enhance flow-based intrusion detection. Using
NF3 datasets, we show that timestamps and IAT metrics
yield meaningful performance improvements across LSTM,
1D-CNN, and Transformer architectures—particularly for
attacks with strong temporal characteristics. The permutation
analysis confirmed their causal importance. Duration features
alone were less impactful, highlighting the added value of
fine-grained time features. NF3 establishes a unified, timeaware benchmark for future research in sequence modelling,
temporal embeddings, and cross-dataset generalisation for
real-world NIDS deployment.
